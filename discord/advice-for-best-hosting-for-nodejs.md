Sure, I can guide you from each point.
Before I say something, it really depends on what kind of needs you have and how far are you willing to go.

There are few options available:

- Cloud Hosting.
- Self Hosted.
- Serverless.

If you have simple website and want to deploy a normal working node website then:

- Namecheap.
- Hostinger.
- Bluehost.

Why?
a. Simple to setup.
b. Cost effective.
c. Cheap yearly pricing with extra accessories like CPanel (which let's you manage your site properly).

Otherwise, if you have an Intense website with many service and other things:

1. TOP Recommendation: AWS — Amazon Web Services.
2. Azure.
3. GCP — Google Cloud Platform.

4. Effective but again depends on case scenario: AWS Lambda alone would very much help in most cases too (would need slightly more config then completely setting up on AWS as a whole from ALBs, to TGs, to whatelse).
